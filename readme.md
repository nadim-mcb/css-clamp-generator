## 📖 How to Use

### 1️⃣ Adjust Your Values
```
Min Font: 16px ────────── Max Font: 32px
Min Viewport: 320px ───── Max Viewport: 1280px
```

### 2️⃣ Preview in Real-Time
Drag the slider to see how your text scales at different screen sizes

### 3️⃣ Copy & Use
```css
font-size: clamp(16px, calc(16px + 16 * ((100vw - 320px) / 960)), 32px);
```

### 🎯 Quick Presets
| Preset | Use Case | Example |
|--------|----------|---------|
| **Heading** | Main titles | 32px → 72px |
| **Body** | Paragraph text | 16px → 20px |
| **Small** | Captions, footnotes | 12px → 14px |
